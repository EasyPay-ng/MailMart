What this page does

Every page in MailMart talks to Cloud Firestore directly, so a page can only work when the security rules in firestore.rules are deployed to the project and the composite indexes in firestore.indexes.json exist. When either is missing, the pages print "Check your Firestore security rules…". This page asks Firestore the same questions the pages do, one at a time, and reports the answer it actually gives.
